# PPA Native 2.5D test gallery

Temporary selection offers **all eight official 3D classes**. It switches
only the locally drawn model. Phoenix Account / Telegram ID / profile class
and production PPA saves remain untouched.

The **shared demo bag + warehouse** persist in the application's private
user:// space, keyed to the Phoenix account. They contain TEST sample items,
not the player's real PPA items. Never send them to the live PPA economy.

Peace City's NPCs are **2D sprites** at the exact deployed PPA coordinates.
NPC service menus are non-transactional beta panels except the shared local
test warehouse. No 3D monsters, pets, bosses or NPCs.

One real server character per Telegram account remains the actual backend
constraint; multiple permanent character slots must be designed later.
